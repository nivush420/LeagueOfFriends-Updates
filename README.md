# League of Friends

Official Windows game releases and permanent launcher updates.

## התקנה חד־פעמית

1. הורידו את [Install-LeagueOfFriends.zip](https://github.com/nivush420/LeagueOfFriends-Updates/releases/latest/download/Install-LeagueOfFriends.zip).
2. חלצו את התיקייה והפעילו את **LeagueOfFriends-Setup.exe**.
3. בחרו **INSTALL**. אחר כך פותחים תמיד את **League of Friends** מקיצור הדרך בשולחן העבודה או מתפריט התחל.

הלאנצ׳ר בודק פאצ׳ים ומציג **UPDATE** כשיש גרסה חדשה. אין צורך להוריד מחדש את כל המשחק בכל שיפור. **VERIFY & REPAIR** בודק ומתקן קבצים; עדכון שנקטע שומר את ההתקנה הקודמת.

## חשבונות שחקן

במשחק: **SIGN IN → NEW PLAYER? CREATE ACCOUNT**. לשחקנים אין צורך בחשבון GitHub או Unity. נכנסים עם שם משתמש וסיסמה, והרמה, ה־XP וה־Friend Coins נשמרים בחשבון בענן.

Friend Coins הם מטבע חשבון נפרד מהזהב בתוך הקרב. משחק שהושלם עם לפחות חמש דקות חיבור פעיל מזכה בתגמול לפי משך המשחק, עם בונוס לניצחון. תגמול שלא הסתנכרן ינסה להישלח שוב בחיבור הבא. שמרו את הסיסמה; איפוס סיסמה עצמי עדיין אינו זמין בגרסת החשבונות הראשונה.

[כל הגרסאות והערות הפאץ׳](https://github.com/nivush420/LeagueOfFriends-Updates/releases)

Windows 64-bit. `stable.json` and the numbered `pack-*.bin` assets are read by the launcher; players do not need to download those files manually. Asset credits and licenses are included with the game.
